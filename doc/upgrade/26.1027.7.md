## 新功能

- **工具参数隐藏**（1.1.5005）：服务器工具详情新增「模型可见参数」复选框组——取消勾选的顶层参数会从模型收到的 inputSchema 中移除，并从模型调用参数中丢弃（上游默认值生效）；必填参数（*）无法隐藏。对 tools/list、$smart 搜索/描述、OpenAPI 规范、上下文占用计算与全部调用路径统一生效。
- **分组指令（Instructions）**（1.1.5002）：分组可配置可选指令文本，MCP 客户端经 `/mcp/{group}` 或 `$smart/{group}` 连接时随 initialize 下发（多数客户端会并入模型系统提示词）。
- **工具调用防护（可选）**（1.1.5002）：高危工具调用参数预检守卫（shell 注入/RCE、云元数据 SSRF/凭证窃取），默认关闭，可通过 `TOOL_CALL_GUARD_ENABLED=true` 环境变量或系统配置 `toolCallGuard.enabled` 开启。
- **MCP 协议版本展示**（1.1.5007）：服务器卡片显示连接协商的 MCP 协议版本（openapi 类型服务器除外）。
- **工具批量筛选**（1.1.5007）：服务器工具配置弹窗新增搜索、注解过滤（只读/破坏性/幂等）与风险分组（读/建/改/删）批量勾选。
- **Elicitation 转发**（1.1.5007）：per-session 隔离工具调用向上游声明 elicitation 能力，上游的交互确认请求（form/url 模式）转发给下游客户端；未声明能力的客户端收到明确错误。
- **上游协议协商配置**（1.1.5007）：streamable-http 服务器新增「协议协商」设置（auto=默认探测 modern / legacy=跳过探测直连 legacy 握手）。
- **On-demand 工具持久化**（1.1.5007）：按需启动服务器休眠前的最后已知工具列表持久化（含启动配置指纹——配置变更后旧快照不恢复），重启后休眠服务器仍展示上次工具列表。
- **远程连接退避重连**（1.1.5007）：断连的远程服务器（SSE/Streamable HTTP）后台自动重连，指数退避 + 抖动（10s–5min 封顶）；服务器卡片显示「重连中/下次重试时间/上次重试」；「连接健康检查」开关现在只控制已连接服务器的健康检查。
- **多语言**：新增西班牙语（1.1.5002）与越南语（1.1.5007）界面；全量补翻法语/土耳其语/越南语历史未翻译条目（以中文语义为基准）；补齐接入端点对话框与 RAG 扫描进度等 15 个缺失文案键；「免登录模式」用户名、RAG 菜单/页面标题（中文名定为「知识库」）等硬编码文案接入国际化。
- **多个向量模型选择与手动向量数据重载**（1.1.5001）；相关度搜索与导入体验优化。

## 修复

- **改密/删用户后旧登录令牌立即失效**（1.1.5004）：登录令牌绑定凭证版本（用户名+密码哈希摘要），每次鉴权回查当前凭证——密码修改、账号删除后，先前签发的令牌即刻拒绝（此前 24 小时内仍有效）。
- **安全修复（GHSA-vgj6-pm6x-8g97 对齐）**（1.1.5007）：`ui://` 动态资源读取遵守分组资源选择与单服务器资源禁用配置；内置提示词/资源不再泄漏到未包含内置服务器的单服务器或分组作用域。
- **Elicitation 转发修复**：修复 slot 双轨断裂导致的转发功能整体失效；转发加 600s 超时与超时后隔离连接驱逐；连接级通知生命周期转发。
- **远程重连可靠性**：修复共享连接会话中途死亡不触发恢复、SSE 回退模式连接类错误不翻转状态、UI/REST 主路径调用死亡不播种恢复调度器等假活问题。
- **界面**：服务器卡片显示上游上报版本（#1367）；展开卡片显示完整描述（#1377）；行布局优化（#1378）；关于对话框不再超出视口（#1376）；暗色模式统一（#1375）；恢复状态文本折行；「允许 HTTP OAuth 令牌端点」桌面文案去除不适用的管理员语义。
