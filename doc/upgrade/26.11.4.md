# 26.11.4

## 新功能

- **决策支持**：RAG 菜单下新增「决策支持」页面——启动开关 + 请求决策历史（按请求时间倒序、分页、详情弹框、一键清空）；全局定时清理任务同步清理决策历史（15 天保留 + 10 万行上限）。
- **决策模型**：设置【本地模型】卡片内新增「决策模型」分段（原【模型和向量】改名【本地模型】、原【模型配置】改名【向量模型】；与向量模型分区显示；卡片头部带「决策支持」标签）——上方「运行中：{模型名}」运行状态行（与知识库同构），下方模型下拉（deploy.json 配置、下载（多源/进度/取消）、选择、打包与向量模型完全一致）；内置 Julia-1 决策模型随安装包分发；所选模型文件丢失时（决策支持已开启）设置页警示，引导重新下载或改用其他模型（该模型已从目录移除时仅引导改选）。启用开关位于「决策支持」页面标题旁（与知识库页一致），设置页不再重复提供。
- **MCP 工具语言**：设置【本地模型】卡体顶部新增「MCP 工具语言」下拉（本地模型级配置，与向量/决策模型分段隔开）——内置工具（rag_*、decision_decide、smart_route_* 等）的描述**与参数说明**语言，默认英文，共 7 个选项：跟随界面语言 / English / 中文 / Français / Türkçe / Tiếng Việt / Español（跟随界面语言随界面语言自动切换）；变更后自动重建智能路由 builtin 索引。
- **工具查看恒可用**：知识库页的「查看工具」按钮不再随功能开关禁用（与决策支持一致）——未开启也能查看工具文档，弹框在确知未开启时提示「暂不会暴露给 MCP 客户端」。
- **决策支持 UI 增强**：决策支持页面标题旁新增 Beta 标签与启用开关、状态文字、「查看工具」按钮（与知识库页标题布局一致）；「查看工具」弹框展示 `decision_decide` 工具的名称、描述与参数 schema，**决策未开启时也能查看**（工具文档与启用状态无关；弹框顶部提示「该工具暂不会暴露给 MCP 客户端」）；侧边栏「决策支持」菜单项带 Beta 标签；知识库页面标题同步补上 Beta 标签（两 Beta 功能页面视觉一致）。
- **决策 MCP 工具**：决策模型启用时，`mcphub-desktop` 内置分组暴露 `decision_decide` 工具（choice/score/noul 三种决策类型，结构化输出分数/概率/选中项）；参数错误返回 -32602（MCP）/ 400（REST），客户端可区分「改参数」与「服务器错误」。
- **相关度搜索**：服务器管理页新增「相关度搜索」对话框（智能路由开启时显示），基于智能路由工具索引的混合检索（向量 + 关键词），支持 全部 / 分组 / 单个服务器 三级范围；结果带相关度评分，对话框显示低于阈值的匹配（附评分供判断），`$smart` 端点仍按设置阈值过滤；索引为空时提示先重建索引。新增 Tauri 命令 `smart_routing_search`。
- **相关度搜索增强**：范围选择器支持搜索与分页；新增「智能路由设置」弹框（向量/关键词搜索权重、最大返回数、相关度评分阈值），参数独立于 RAG 设置并直接参与实际搜索；搜索按钮配色与 RAG 页统一。
- **中英文混合检索**：智能路由关键词检索支持中英文互查——中文查询可匹配英文工具描述，反之亦然（内置中英术语词典双向扩展，向量检索由多语言嵌入模型天然支持）。
- **运行时版本**：Node/Python 保底 LTS 版本列表更新至最新；下载脚本动态获取「最新 LTS 的前一版本」作为内置默认版本（不再代码写死，网络失败回退保底值）。
- **uv 升级**：捆绑 uv 升级至 0.13.7，且下载脚本改为总是获取最新版本（`releases/latest` 动态解析，网络失败回退 0.13.7）。
- **修复**：RAG 设置弹框标题由「搜索设置」改为「RAG设置」；移除 Vite 配置 `__dirname` 弃用警告（改用 `import.meta.dirname`）。
- **修复**：相关度搜索弹框高度过矮与范围下拉被弹框边缘遮挡的问题（下拉改用固定定位，不再被滚动容器裁剪）。
- **仪表盘**：智能路由开启时新增「智能路由上下文占用」统计（$smart 元工具定义的 token 估算）。
- **智能路由设置**：改为 1 行 1 项布局（与 RAG 设置一致）。
- **决策历史标准分页**：决策支持页请求历史由「加载更多」（上限 500 条）改为标准分页（上一页/下一页 + 页码，每页 50 条），支持浏览全部历史。
- **仪表盘布局调整**：上下文占用移至第二行（与智能路由上下文占用同行）；第一行新增「分组数」统计。
- **决策工具能力边界说明**：`decision_decide` 工具描述明确声明模型为小型本地路由模型——适合选项挑选/工具路由/相关度评分，不适合事实性、计算或知识类问题（六语）。
