# 26.11.2

## 修复

- **更新下载停滞永久挂起**：下载连接停止吐数据但不报错时（reqwest 默认无读超时），「正在下载」永久卡死、无任何终态事件。新增 60s 停滞看门狗（15s tick 检查最后进度时间戳），超时以明确错误终止，UI 回到可重试状态。
- **更新失败/取消后无法直接重试**：失败与取消路径此前会关闭 `Update` 资源（rid），而前端缓存的更新对象仍持该 rid，再次点击「安装更新」会撞失效资源。现在仅成功时释放资源（`download_and_install` 为 `&self`，Update 可复用），失败/取消后可直接重试。
- **下载初始进度条误导**：GitHub Releases 下载会 302 重定向，首个数据块到达前「不确定态」进度条渲染为 1/3 宽度实心条，视觉上像已进度 33% 且卡住。改为全宽低透明度脉冲 + 「连接中...」文案（4 语言），不再与真实进度混淆。
