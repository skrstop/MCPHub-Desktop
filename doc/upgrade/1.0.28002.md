## 新功能
- 仪表盘 MCP 端点卡片新增「复制 MCP 配置」按钮：一键复制可直接粘贴到 Claude Desktop / Cursor 等客户端的 `mcpServers` 配置，方便分享给他人使用。
  - 每个端点行（ALL / GROUP / SERVER / 设置页 SMART）都有独立的「复制配置」图标按钮，与「复制 URL」按钮并排。
  - 开启 Bearer 鉴权时自动带鉴权头：仅 1 个启用密钥时直接填入真实 token（粘贴即用）；多个密钥或无密钥时用 `Bearer <your-bearer-token>` 占位，并在 toast 提示去密钥管理复制要用的 token（避免替用户挑选、且不把真实 token 写进可分享配置）。
- HTTP 服务启动失败时弹出**模态对话框**（替代易被忽略的 toast）：显示服务地址与按错误类别本地化的失败原因 + 处理建议，并提供「重试启动」按钮。关闭弹框后，仪表盘右上角出现**常驻三角警示图标**，点击可重新打开弹框；服务恢复运行后图标与弹框自动消失。
- **DB 日志文件镜像**：应用日志在写入 `app_log` 表的同时，同步追加到 `<应用数据目录>/logs/app-YYYY-MM-DD.log` 按天分文件；清理策略与 DB 一致（15 天，每 6 小时随 DB 清理一起删除过期日志文件）。
- **启动崩溃日志**：应用数据目录新增 `crash.log`，捕获 panic / 数据库初始化失败的堆栈与原因（首启失败时不再静默退出）。
  - 位置：Windows `%APPDATA%\app.mcphub.desktop\crash.log`，macOS `~/Library/Application Support/app.mcphub.desktop/crash.log`，Linux `~/.local/share/app.mcphub.desktop/crash.log`。

## 修复
- 修复 RAG 搜索权重默认值与 HTTP 服务默认端口在新装用户上仍为旧值（0.5/0.5、3000）的问题，统一为 0.9/0.1 与 23333，并为已安装用户自动迁移（DB 迁移 v18/v19）。
- 修复新装用户设置页 SMART 端点端口与 HTTP 服务实际监听端口不一致的问题：桌面端所有端点/URL 显示统一从 `httpPort` 派生，不再使用独立的 `install.baseUrl` 端口。
- 修复 Windows 首次安装后从安装程序（`.exe` / NSIS）启动闪退、需手动重开一次才正常的问题：
  - 保留 per-machine（按机器）安装选项（`installMode: both`）；
  - 应用启动时检测到提权运行（安装程序「完成后启动」以提权身份拉起）则用 `explorer.exe` 非提权重拉自身并退出，从根上规避提权首启闪退，同时不改变安装方式；
  - 增加启动崩溃日志与数据库初始化失败容错（不再静默 panic 退出）。
- Windows 下 HTTP 服务因防火墙无法启动时，界面弹出明确提示并在日志中体现（含防火墙放行指引）；服务正常启动但外部不可达时，日志补充防火墙排查提示。失败原因按类别（端口占用 / 权限拒绝-防火墙 / 端口不可用 / 其他）分别展示对应的简短原因与处理建议，不再一股脑罗列所有可能。
- 修复 HTTP 服务启动失败弹框点「重试」后错误类型对不上的问题：重试失败改为重新拉取后端权威状态（含正确 errorKind），不再用通用提示覆盖真实原因。
- HTTP 服务优雅关闭增加 10s 超时兜底，避免长连接（SSE / Streamable HTTP）导致关闭挂死或旧任务泄漏（镜像上游 #1042）。
- 修复游客（skipAuth）模式下设置页新增 Bearer 密钥提示「无权限」：`bearer_keys` 命令的鉴权缺少 skipAuth 放行，现已与其它设置命令对齐。
- Bearer 密钥管理多项修复：
  - 密钥行 token 旁新增常驻「复制」按钮，可随时复制完整 token；移除原先一次性「请立即复制，之后不再显示」横幅（且横幅在暗色主题下看不清）。
  - 修复新增密钥后「添加」按钮消失的问题（创建后表单未收起）。
  - 启用状态文案国际化（原先硬编码 Active/Inactive）。
  - 访问范围选「全部」时不再显示禁用态的「允许服务器/分组」下拉框。
  - 移除无后端效果的「密钥类型（系统级/用户级）」与「属主」选择器：桌面端后端不存这两个字段（原为 UI 装饰，选「用户级」会导致访问范围 UI 被隐藏、密钥固定全量访问）。现在所有密钥默认系统级，管理员始终可设访问范围。
  - 复制 MCP 配置时鉴权头改为取真实密钥 token（原先用始终为空的 legacy `bearerAuthKey` 字段，导致鉴权头为空）。
  - 后端密钥范围校验已确认正确（all/groups/servers/custom 均按 access_type 过滤可达服务器）。
- 其他已知问题修复与依赖升级。
