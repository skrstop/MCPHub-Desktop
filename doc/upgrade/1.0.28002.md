## 新功能
- 仪表盘端点卡片：单个复制按钮下拉「复制 URL / 复制 MCP 配置」。GROUP/SERVER 行的 URL 及复制的配置均用占位符 `<分组名>`/`<服务名>` 提示可变；开启鉴权时配置带鉴权头（单密钥填真实 token，多密钥用 `<your-bearer-token>` 占位）。
- HTTP 服务启动失败时弹**模态对话框**：服务地址 + 按错误类别本地化的原因/建议 + 重试按钮；关闭后仪表盘右上角常驻三角警示角标，可重开弹框，服务恢复后自动消失。
- **日志文件镜像**：应用日志在写 `app_log` 表的同时，按天追加到 `<应用数据目录>/logs/app-YYYY-MM-DD.log`，15 天清理（与 DB 同策略）。
- **启动崩溃日志**：`<应用数据目录>/crash.log`，捕获 panic/DB 初始化失败，首启失败不再静默退出。
- 「安装更新」增加进度显示

## 修复
- RAG 权重 / HTTP 端口默认值：新装用户旧值（0.5/0.5、3000）统一为 0.9/0.1、23333，并迁移已装用户（DB v18/v19）。
- 桌面端所有端点/URL 显示统一从 `httpPort` 派生，不再用独立的 `install.baseUrl`。
- Windows 首次安装后从安装程序启动闪退：保留 per-machine 安装，启动检测提权则 `explorer.exe` 非提权重启，根上规避提权首启闪退。
- HTTP 服务因防火墙无法启动时弹框 + 日志体现；优雅关闭加 10s 超时兜底，避免长连接挂死（镜像上游 #1042）。
- 游客（skipAuth）模式新增 Bearer 密钥「无权限」：补齐 skipAuth 放行。
- Bearer 密钥：token 行内随时复制、新增后按钮不消失、启用状态国际化、`all` 时隐藏范围下拉、移除无效的「密钥类型/属主」选择器、复制配置改用真实 token；后端范围校验确认正确。

## 依赖
