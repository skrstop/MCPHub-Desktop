## 新功能
- **全文索引（FTS5 + 中英/拼音分词）**：服务器、分组、RAG 文档、技能、内置 Prompts/Resources、应用日志七张 FTS 表，支持中文按词、英文原词/前缀、拼音全拼、拼音首字母四种命中方式（搜「数据」「shuju」「sj」均能命中「数据库服务」）；分词器采用 charabia 全语言（中文 jieba 词级切分 + 繁简归一，简繁输入互通），拼音列由 pinyin 逐字生成
- **搜索结果相关度优先排序**：命中查询词元数第一优先（双词命中的结果排在单词命中的前面），同相关度保持原排序（名称/时间序）；覆盖服务器、分组、技能、Prompts、Resources、日志、RAG 全部搜索入口
- **数据库迁移前自动备份**：检测到待执行迁移时自动生成一致性快照 `mcphub.db.bak`（VACUUM INTO），无待迁移不生成不覆盖
- **活动日志筛选优化**：移除「用户」筛选条件（桌面端无用户追踪语义）；服务器/工具/分组/API 秘钥四个筛选改为可搜索的分页下拉框（输入即过滤、滚动加载更多），分组与 API 秘钥筛选真正生效，统计条与筛选联动
- **应用日志全文检索**：日志页搜索框接入后端 FTS（中/英/拼音均可命中 message，最多返回 200 条，相关度排序）

## 修复
- 多词查询语义修正：FTS 多 token 由隐式 AND（必须全词命中）改为 OR（命中任一 token 即召回），多词查询不再漏数据
- 服务器搜索相关度被命令层按名重排覆盖（如 "idea sse stream" 中仅命中 1 词的服务排第一）：命令层统一按相关度排序
- 工具名兜底匹配升级为 token 级计数（原要求完整关键词子串，多词查询几乎永不命中）
- FTS 零结果/空表/异常统一降级原 LIKE 子串查询，补词前缀匹配盲区
- 存量 RAG 文档未入 FTS 索引：应用重启后自动对账回填自愈
- 日志清理与 FTS 索引同事务联动，无孤儿行
- 删除 `[http-server-watch]` 周期性 heartbeat 调试日志（此前每 30 秒刷一条，淹没正常日志）

## 限制
- 拼音词中前缀搜不到（FTS5 前缀只从 token 头部匹配）；多音字取最常见读音
