# MCPHub Desktop 1.0.35003

## 新功能
- **RAG 导入统一为「数据源选择」**：原「文件 / 文件夹」双入口合并为一个数据源分段切换器（文件 / 文件夹 / Git 三选一），选择 Git 时在同一表单内输入仓库地址与可选参数（branch / depth / 账密——点「更多参数」展开），拉取成功后直接展示仓库内文件的分组扫描树
- **Git 数据源（gix 纯 Rust 集成）**：通过 gitoxide（gix）以库形式编译进应用（无外部 git 依赖），支持 HTTPS 浅克隆（depth 默认 1，最大 100）与指定 branch；带认证仓库在表单内输入账密（或 Token），认证失败内联报错并自动展开账密区，凭证存入本机（应用数据目录内凭证文件），后续更新免重复输入
- **Git 两段式存储**：扫描阶段仓库 clone 到系统临时目录（`mcphub-rag-git/{hash}`，免清理）；确认导入后才拷贝落盘到应用数据目录（`rag/git/{hash}`），取消导入无残留
- **文档列表树形视图**：新增平铺 / 树形切换；树形按「数据源 → 物理目录 → 文件」三级展示，文件夹与 Git 数据源节点显示类型徽章，支持一键展开 / 收起；存量历史文档自动归入对应来源目录或通用「文件」节点（不改写历史数据，纯展示层归类）
- **MCP 工具 `rag_file_create` 不再覆盖同名文档**：重名一律并存（与上传路径语义统一），通过工具创建的文档统一归入「MCP 工具」树节点
- **「自动同步删除文件」开关（默认开启）**：更新检查时源文件已删除的文档自动移除（文件 / 文件夹 / Git 数据源均生效）；可关闭——关闭后不再自动删除，列表对失效文档显示「原始丢失」告警徽章
- **文件夹级联勾选**：主页树形列表与导入弹框的文件列表中，文件夹（含数据源节点、平铺分组头）均可勾选——勾选则选中其下所有文件（含子文件夹），已全选时点击取消，部分选中显示半选状态

## 优化
- Git 仓库更新策略：仓库级浅克隆刷新（60 秒去重缓存）+ 文档级 md5 判定，接入单条检查 / 批量更新 / 自动定时更新三条链路；无凭证的私有仓库在自动更新时跳过并记日志
- 删除 Git 数据源的最后一个文档后，自动清理持久 clone 目录与本机凭证
- **文件夹 / Git 数据源级同步**：批量 / 自动更新检查现在覆盖新增与删除——数据源目录中新出现的文件自动导入（文件夹走软链接、Git 走拷贝），源文件已删除的文档自动移除；确认弹框展示「数据源新增文件 / 已删除文件」计数；扫描截断或根目录丢失时跳过删除判定（防误删），删除需同时满足「扫描缺失 + 磁盘不存在」双重条件
- **Git 数据源失效提示**：外部原因导致仓库拉取失败时主动提示而非静默用过期克隆——批量预览弹框按仓库列出失败原因（认证失败 → 引导重新选择数据源并输入新账密；其他 → 地址可能已变更或网络不可达），单文档「检查更新」弹框同步显示该仓库的刷新失败警示；批量更新进度弹框右上角新增数据源状态图标（点击查询后端记录的最近刷新失败，无失败显示绿色对勾），失败信息结构化（auth/其他），修复路径 = 导入弹框重选仓库输入新凭证（成功即更新本机凭证）

## 优化
- **导入弹框布局重设计**：数据源 / 导入方式 / 选择入口 / Git 表单 / 自动同步开关统一收进「导入配置」分区卡片，格式说明移到卡片下方，层次更清晰

## 修复
- 修复 SSH 连接在 `~/.ssh/config` 使用 `ProxyCommand nc -v`（如 GitHub 走 443 代理）时必定失败的问题：拉取时自动安装 stderr 过滤 wrapper，`nc -v` 的成功输出不再被误判为连接错误
- 修复 **http + 账密** 仓库无法认证的问题（内网自建 GitLab/Gitea 常见）：放行 http 明文 basic-auth（此前 gix 默认拒绝），https 行为不变
- 修复 **http 地址被服务器重定向到 https 时认证失败** 的问题（重定向会剥离凭证）：拉取前自动跟随重定向升级为最终地址（http/https 两种写法归一到同一数据源），本地 git 可用的仓库现在都能正常导入
- 修复认证失败时**控制台出现密码输入提示并卡住**的问题（http/SSH 通用）：禁用 gix 的终端交互提示，认证失败改为在页面内联提示账密表单

- **移除 Git 数据源记忆**：不再保留「已导入数据源」下拉与数据源注册表——每次导入需重新输入仓库地址（输入过的账密仍保存在本机，刷新更新时自动使用）；失效提示中的「重选数据源」路径改为重新输入地址
- **修复 Git 导入「取消」按钮不生效**：取消令牌按 URL 规范化后的形式注册，前端传入的原始地址（http→https 重定向、带尾斜杠等场景）匹配不上导致取消静默失败；现取消时同样先规范化再匹配，并用标志位消除信号丢失竞态
- **导入弹框列表交互简化**：目录/分组行与文件行上的「全选/清除/−」按钮全部移除——列表只剩勾选逻辑；文件夹行（树形目录头 / 平铺分组头）**整行点击 = 折叠/展开**（平铺分组同样可折叠，收起时显示文件计数摘要）；**文件行整行点击 = 选中/取消选中**（未勾选文件灰色弱化态显示，点击即勾选）
- **导入弹框扫描结果平铺/树形切换**：统计条右侧新增「平铺 / 树形」分段切换（默认树形）——平铺 = 一组一行的分组列表；树形 = 目录层级可折叠；两种视图同一交互（只显示已勾选文件、目录/分组级全选与清除、整行点击取消勾选）；**移除文件行的「删除」按钮**——列表只保留勾选/取消勾选逻辑，误加的文件取消勾选即可（不会被导入）
- **导入弹框扫描结果改为目录树展示**：文件列表从平铺分组改为按物理目录链的树形结构（目录节点可折叠，显示「已选/总数」，目录级「全选/补选/清除」作用于该目录全部文件含子目录）；默认全部收起，列表右上角一键展开/收起；未勾选任何文件的目录分支和文件行直接隐藏（不会被导入）；文件夹行和文件行**整行点击**即折叠/勾选（不必点中小按钮）
- **修复导入弹框文件勾选失效（真正根因）**：取消勾选一次后，后续点击不再有任何反应——根因是勾选集合被**原地修改**（React 判定「数据没变化」而直接忽略后续所有更新）；现改为每次先复制集合再修改，连续点击勾选/取消全部正常生效
- **修复勾选行被隐藏无法重新勾选**：取消勾选的文件行/目录分支此前会立即从列表中消失（无法再点击勾回）；现在所有扫描到的文件和文件夹常显，未勾选的以灰色弱化态展示
- **修复「自动同步新增文件」开关关闭时批量/自动更新的行为**：确认弹框不再虚报「N 个新文件待导入」（此前显示但实际不导入）；自动定时更新在仅有新增文件待导入（开关关闭）时正确空转跳过，不再每个周期空跑一遍并打扰界面
- **修复平铺视图「全部收起」不生效**：根目录分组的折叠标识与树形不一致（空路径 vs 根节点键），导致点「全部收起」后根分组不收起；已统一标识
- **修复文件夹扫描时树形视图空白**：根目录下的文件此前不会出现在树形结构中（只有平铺能看到），现在以「(根目录)」节点展示
- **修复 RAG 关闭时导入弹框无法点击**：页面整体禁用态会连坐模态框，导致弹框内所有按钮静默失效

- **修复系统代理干扰 Git 探测**：克隆前的地址规范化探测（http→https 升级）会走系统代理，代理软件（如 Clash）可能对 git 协议请求返回错误结果导致升级失效；现在该探测直连不走代理
- **Git 拉取进度与速度显示**：拉取仓库时按钮下方实时显示下载进度条（已接收/总字节百分比，pack 大小未知时为流动条）与实时速度（EMA 平滑），取消或完成后即隐藏
- **Git 账密改为本地文件存储**：从系统钥匙串迁移到应用数据目录内的 `git-credentials.json`（权限 0600、原子写入）——此前每次自动更新访问钥匙串都会弹出系统授权确认框，几分钟一次的更新检查会被打断；现在更新检查完全零交互，首次在旧版本存入钥匙串的账密需在导入时重新输入一次
