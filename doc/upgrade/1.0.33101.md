## 新功能
- 文件夹扫描，支持扫描子文件夹
- **RAG 文档导入支持 PDF / Office / 图片解析**（提取为 Markdown 存储）：
  - 新增 7 种办公文档格式：`.pdf` / `.docx` / `.doc` / `.xlsx` / `.xls` / `.pptx` / `.ppt`（含 Legacy 二进制格式），导入时自动提取为 Markdown 后走既有 chunker → embedding → lancedb 管线，查看/分片/搜索按 Markdown 渲染
  - 新增 8 种图片格式：`.png` / `.jpg` / `.jpeg` / `.gif` / `.bmp` / `.webp` / `.tiff` / `.tif`，通过系统 OCR 引擎识别文字后导入（macOS 用 Apple Vision、Windows 用 Windows.Media.Ocr、Linux 需安装 tesseract）
  - PDF / Word / PPT 内嵌图片同样过 OCR，文字以「图片OCR」引用块并入文档
  - 导入弹框增加 OCR 可用性预检提示；Linux 缺 tesseract 时弹框展示对应发行版的安装命令（apt / dnf / pacman）并支持一键复制
- 提取层重构为策略模式（`ContentExtractor` trait + 注册表派发），纯文本导入行为不变

## 修复
- 升级相关依赖类库版本

## 限制
- 扫描版 PDF（图片型、无文字层）依赖 OCR：有 OCR 引擎时整篇靠 OCR 恢复，无引擎时报「内容提取失败」并提示原因
- `.ods` / `.xlsm` / `.xlsb` 等开放/宏格式不在支持范围
