## 新功能
- **技能与 RAG 文档列表「全选本页」**：分页页脚左侧新增全选按钮，一键勾选/取消当前页全部条目；选择集跨页保留（不影响其他页已选项），支持既有批量操作（技能导出、RAG 批量打标签/删除）
- **技能导入弹窗搜索过滤**：新增 Agent 搜索（按名称/路径）与 Skill 搜索（按名称/描述/目录名）两个过滤框，纯前端过滤、实时生效；Skill 搜索时无命中的分组整体隐藏、命中的分组自动展开
- **一键过滤无 skill 的 Agent**：导入弹窗搜索行新增「只看有 skill 的 Agent」切换按钮，默认开启（隐藏扫描不到任何 skill 的空 Agent，减少噪音），点击可切换显示全部

## 修复
- Skill 扫描误报 Agent 内部目录：扫描跳过点号开头的隐藏条目（如 Codex 自带的 `.system` 内置系统技能目录），不再出现在导入列表
- 自定义 Agent 名称含中文/非 ASCII 字符时保存报错（"agent name must contain alphanumeric chars"）：id 生成改用 Unicode 字母数字；纯符号名称自动回退为基于名称哈希的稳定 id
