### 记录不修（理由）
- **R151 bearer token 明文落库 + 非常量时间比较**（设计债：桌面单机 DB 即信任边界；改 SHA-256 需迁移 + 前端一次性回显流程，单独排期）。
- **R151 `CorsLayer::permissive()` + 默认无鉴权**：本地端口任意网页可跨域调 MCP 工具——桌面本地服务常见取舍，开启 bearer 为联网环境前置条件（文档已有说明）；加 Origin 校验单独排期。
- **L-117-1 prompts/resources 不应用 bearer allow-list**（存量非回归，旧行为相同；含资源正文可读）。
- **R152 E2E 缺口**：SSE 上游传输 × 全矩阵、DELETE × scope 通道（session 清理中间件）、subscriptions/listen × scope 通道——本轮新增套件部分补齐（meta 门控/tasks 分代/缓存注入/三版本真实调用），SSE 上游本地 fixture 服务器待建（记待办）。
- **R149 单测债**：本轮补 parse_body_limit / is_known_protocol_version / tasks TTL 三组；leniency 中间件与 bridge to_call_response 需进程内 harness，待办。
- registry `get_registry_server_version` 命令注册后无 E2E（Tauri IPC 面不易黑盒触发），靠 cargo check + 前端路由对照守卫。
