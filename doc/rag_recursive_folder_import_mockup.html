✎ 交互与实现说明(确认页面后按此实现)

交互流

  • 入口不变:仍是 UploadDialog 里的「选择文件夹」按钮;新增「包含子文件夹」开关(默认关?或默认开——待确认)。
  • 开关关时 = 现有行为(仅一级文件),列表保持扁平样式;开关开时 = 递归扫描,列表变为分组树。
  • 分组树:组头勾选框 = 整组全选/取消;箭头 = 展开/收起;文件行 hover 出现 ✕ 可单个移除;已导入路径红色提示(现有逻辑)。
  • 取消勾选的文件不参与上传;底部按钮徽标实时显示「实际将导入 N 个」。
  • 「重扫」按钮 = 重新弹出 OS 目录选择框并按当前开关重新扫描。

后端改动(确认页面后实现)

  • 新增 runtimes/rag/folder_ignore.json(✅ 已创建,51 个开发类目录名,按目录名任意层级匹配;隐藏目录由点开头规则处理)。include_str! 编译期内置,模式同 file_support.json。
  • pick_rag_folder 命令增加参数 recursive: bool;递归时应用 folder_ignore.json 排除(无开关,自动生效),复用现有扩展名白名单 + 8KiB 内容嗅探过滤。
  • 返回结构升级为 { root, groups: [{ relPath, files: [{path, name, size}] }], totalFiles, truncated };扁平模式下 groups 只有一组,前端两种渲染兼容。
  • 递归用 walkdir(需新增依赖);跳过符号链接目录防循环;上限 500 文件 + 截断标记。
  • 「文件多选」入口返回结构不变,前端统一转成单组。
